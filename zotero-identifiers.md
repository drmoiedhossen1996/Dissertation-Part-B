## How to import

In Zotero: **Add Item by Identifier** (magic-wand icon) → paste all lines at once
(Shift+Enter opens the multi-line box) → Zotero fetches metadata from CrossRef/PubMed.

Do not type bibliographic records by hand. Every reference error in this project came from typing or
reassembling an entry rather than fetching it. A wrong identifier fails visibly; a wrong typed record
does not.

## Four in-text markers to check individually after Zotero numbers the citations

Two author pairs account for every citation error in Part B.

| Reference | Must support | Must appear |
|---|---|---|
| **Kamphuis 2018** (*Int J Cardiovasc Imaging*) | scan–rescan reproducibility | Discussion 4.5; reproducibility half of Introduction 1.2 |
| **Kamphuis 2021** (*Am J Physiol*) | positive stroke-volume/vorticity correlation | Discussion 4.2 only |
| **Binter 2016** (*Magn Reson Med*) | spatial-resolution sensitivity of viscous energy loss | Introduction 1.2; Discussion 4.2 |
| **Binter 2017** (*Circ Cardiovasc Imaging*) | aortic turbulent kinetic energy and AS severity | Introduction 1.3 and 1.4; not in the Discussion |

If any of these lands on the wrong sentence, the claim it supports becomes unsupported and the error is
invisible in the reference list.

## Before inserting citations

Confirm the citation style required by the MRes handbook. Current drafts use Vancouver numeric.
Set the style in Zotero before inserting; changing numbering scheme mid-document is where markers drift.
