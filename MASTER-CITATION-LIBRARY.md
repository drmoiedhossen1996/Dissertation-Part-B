multi-line box → paste all 16 lines → Zotero fetches authoritative metadata from CrossRef/PubMed.

### Why identifiers rather than a .ris or .bib file

Do not type or paste bibliographic records by hand. Every reference error in this project came from
typing or reconstructing an entry rather than fetching one. An identifier that is wrong fails visibly
on import; a typed record that is wrong is invisible.

The reference details printed below are for **verifying what Zotero fetched**. They are not for typing
into Zotero.

## Two import traps

**Vahanian.** PubMed also holds a German translation of these guidelines under a different PMID, with
the title in square brackets. The DOI above returns the English original in *European Heart Journal*.
If Zotero fetches a bracketed title, you have the translation.

**Two author pairs, four papers.** Bold text in the table marks the co-authors that distinguish them.
After Zotero numbers your citations, confirm each of these four resolves to the intended paper:

| Paper | Subject | Cited in |
|---|---|---|
| Binter **2016** (*Magn Reson Med*) | voxel size and viscous energy loss | Introduction 1.2 · Discussion 4.2, 4.4 |
| Binter **2017** (*Circ Cardiovasc Imaging*) | aortic turbulent kinetic energy and AS severity | Introduction 1.3, 1.4 · Discussion 4.4 |
| Kamphuis **2018** (*Int J Cardiovasc Imaging*) | scan–rescan reproducibility | Introduction 1.2 · Discussion 4.5 |
| Kamphuis **2021** (*Am J Physiol*) | stroke volume and vorticity | Discussion 4.2 only |

## Errors this library replaces

Corrected during the audit, recorded so they are not reintroduced:

- **Dyverfeldt** — three drafts, two non-existent entries. One conflated a 2009 *Magn Reson Imaging*
  author list with a 2006 *Magn Reson Med* title; another gave a 2008 paper with the wrong journal.
  The correct paper for the turbulent kinetic energy / irreversible pressure loss claim is item 6 above.
- **Kamphuis 2018** — appeared with Kamphuis 2021's author list.
- **Binter 2016** — appeared with Binter 2017's author list, twice.
- **Adriaans** — appeared twice under two different numbers in one Introduction reference list.
- **Garcia** — journal changed between drafts to *J Cardiovasc Magn Reson* 21:28, picking up the journal
  of the adjacent entry. Correct journal is *JACC Cardiovasc Imaging*, as above. **This error is still
  present in the Introduction reference list in the repository** and will be removed when that list is
  deleted.
- **Eight invented titles** in one Discussion reference list — paraphrases rather than actual titles,
  which read as fabricated citations to anyone who searches them.

Every one of these came from typing or reconstructing an entry. None would have occurred with a
DOI/PMID import.

## Before inserting citations

1. Confirm the citation style required by the MRes handbook. Current drafts use Vancouver numeric.
2. Set the style in Zotero **before** inserting anything.
3. Delete the existing reference lists from Introduction.docx, Methods.docx and Discussion.docx.
   Zotero generates one merged bibliography for the whole of Part B.
4. Work through CITATION-INSERTION-GUIDE.md section by section.
